# InfraView 总览状态、刷新周期与数据源展示设计规格

最后更新：2026-07-27

## 目标

在不改变 InfraView 只读边界的前提下，完成以下优化：

- 总览卡片中的严重、警告、离线、未知和指标异常计数为零时，以正常绿色和明确的“无…”文案展示，避免零值仍呈现异常颜色。
- 当前可见业务页面每 15 秒自动刷新；未挂载页面不刷新，浏览器后台标签页不刷新，前一请求未完成时不发起重叠请求。
- Nightingale 当前指标缓存调整为 15 秒；主机静态资产和历史范围缓存保持 60 秒。
- 数据源状态 API 返回真实运行时数据源类型，左下角显示 `Nightingale` 或 `Mock`，不再硬编码。
- 浏览器自动刷新周期由后端运行时配置返回并统一使用，避免前后端配置漂移。

## 总览正常态

总览板块结构和尺寸保持不变，只调整状态语义：

- `critical_hosts=0` 显示绿色“无严重”，大于零时显示红色“严重 N”。
- `warning_hosts=0` 显示绿色“无警告”，大于零时显示黄色“警告 N”。
- `offline=0` 显示绿色“无离线”，大于零时显示红色“离线 N”。
- `unknown=0` 显示绿色“无未知”，大于零时显示未知状态色“未知 N”。
- 单项指标 `warning=0` 且 `critical=0` 时显示绿色“无异常”；存在异常时继续显示“严重 N · 警告 N”并沿用最高等级颜色。
- 在线数量继续显示绿色“在线 N”。

零值不隐藏，以保持卡片布局稳定，并明确表示系统已经检查过该状态。

## 刷新与缓存

`INFRAVIEW_REFRESH_INTERVAL` 默认值改为 `15s`，并通过数据源状态 API 返回整数秒。前端使用该运行时值驱动：

- 总览查询；
- 当前主机列表查询；
- 左下角数据源状态查询；
- 刷新控件中的周期说明。

React Router 只挂载当前路由，因此总览和主机页不会同时轮询。所有查询继续设置 `refetchIntervalInBackground=false`，并依赖 React Query 的现有行为避免同一查询重叠执行。

后端缓存默认值：

| 数据类别 | 默认 TTL |
| --- | --- |
| 当前指标 | `15s` |
| 主机清单与静态资产 | `60s` |
| 历史范围与聚合范围 | `60s` |
| 数据源健康状态 | `15s` |

私密部署环境若显式配置旧的 `30s` 或 `20s`，重新部署前只更新上述两个非敏感周期变量，不读取或输出其他内容。

## API 契约

`GET /api/v1/datasource/status` 的 `data` 新增：

```json
{
  "type": "nightingale",
  "healthy": true,
  "checked_at": "2026-07-27T00:00:00Z",
  "refresh_interval_seconds": 15
}
```

- `type` 只可能是后端已经校验过的 `mock` 或 `nightingale`。
- `refresh_interval_seconds` 来自 `Config.RefreshInterval`，按整秒返回；配置要求不小于 1 秒且必须为整秒，禁止静默截断。
- 前端把类型映射为 `Mock` 或 `Nightingale`，不根据健康结果猜测数据源类型。
- API 不返回 Base URL、Token、PromQL 或其他上游配置。

## 前端数据流

`AppShell` 继续唯一请求数据源状态，并通过嵌套路由 `Outlet` 上下文向当前业务页面提供 `refreshIntervalMs`。总览页和主机页在没有路由上下文的独立测试环境中使用 15 秒安全默认值。

`RefreshControl` 接收明确的 `refreshIntervalSeconds` 属性并展示真实周期，不再包含固定 30 秒文案。

## 错误与降级

- 数据源状态首次请求尚未完成或失败时，左下角类型显示中性“数据源”，当前业务页面使用 15 秒安全默认周期。
- 已有状态数据进入 stale 或后台刷新失败时，继续展示后端最近一次成功返回的真实数据源类型和刷新周期。
- 本次不改变现有旧缓存降级、中文错误、认证失效处理及只读 Provider 边界。

## 测试与验收

必须按 TDD 覆盖：

- 总览全正常时不出现红色或黄色零值，显示“无严重、无警告、无离线、无未知、无异常”。
- 存在异常时仍显示对应计数和等级。
- 总览、主机列表和数据源状态在 15 秒边界刷新，未到边界不刷新，请求未完成时不重叠。
- 刷新控件显示后端周期。
- 数据源状态 API 返回真实 `type` 和 `refresh_interval_seconds`。
- 配置默认刷新周期和当前指标 TTL 均为 15 秒，资产及范围 TTL 仍为 60 秒。
