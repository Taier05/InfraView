# InfraView 产品与交互设计

## 目标用户与原则

面向需要集中查看 Linux 基础设施状态的运维人员。界面采用低饱和深色中文控制台，桌面优先并兼顾常见平板宽度。状态同时使用颜色和文字，不能只靠颜色表达。

核心原则：轻量、只读、真实状态、明确降级。页面不出现行级操作菜单，也不展示重启、删除、执行命令、修改或发布入口。

## 页面

### 登录

固定账号密码登录。页面明确说明只读边界；失败显示简体中文错误。登录成功进入总览，未认证访问业务路由会重定向到登录页。

### 总览

展示主机总数、在线/离线/未知、CPU 平均使用率、内存平均使用率和 CPU/内存聚合趋势。支持 1 小时、6 小时、24 小时、7 天和手动刷新，默认 24 小时，每 30 秒自动刷新。

### 主机列表

支持主机名或 IP 搜索、在线/离线筛选、名称/CPU/内存/负载/运行时间排序和分页。查询状态写入 URL，刷新与分享 URL 后可恢复。列表只有进入详情的链接，无业务操作列。

### 主机详情

展示身份、在线状态、IP、OS、运行时间、当前 CPU/内存/负载/磁盘 I/O/网络速率、文件系统容量，以及按单位拆分的四组真实 ECharts canvas 趋势。当前指标和历史指标错误相互隔离。

## 加载、空态与错误

- 首次请求显示页面级加载状态。
- 指标缺失显示“暂无数据”；空文件系统显示“没有文件系统数据”。
- stale 数据显示“数据已过期”和采集时间。
- 没有缓存时显示明确错误；可重试错误提供只读“重试”按钮。
- 主机不存在显示数据源语义错误，不伪装成普通离线。
- 后台刷新失败时，主机详情保留已缓存内容并独立提示刷新失败。

## 可访问性与真实浏览器验收

页面使用语义化 heading、table、label、alert 和状态文字；趋势图包含屏幕阅读器摘要。Playwright 在真实 Chromium 中验证 canvas 的位图尺寸和 CSS 尺寸均大于零，并验证不存在破坏性按钮或链接。
